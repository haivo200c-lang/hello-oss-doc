# Hello OSS

## 1. Giới thiệu dự án

Hello OSS là một dự án phần mềm mã nguồn mở đơn giản được viết bằng ngôn ngữ C. Chương trình có chức năng hiển thị dòng chữ "Hello OSS" trên màn hình.

Dự án được xây dựng nhằm thực hành quản lý mã nguồn, xây dựng tài liệu hướng dẫn và tìm hiểu quy trình đóng góp cho phần mềm mã nguồn mở.

## 2. Mục tiêu dự án

- Làm quen với quy trình phát triển phần mềm mã nguồn mở.
- Thực hành sử dụng Git và GitHub.
- Tìm hiểu cách xây dựng tài liệu README và CONTRIBUTING.
- Tìm hiểu các loại giấy phép phần mềm mã nguồn mở.

## 3. Yêu cầu hệ thống

- Hệ điều hành Windows.
- Trình biên dịch GCC.
- Công cụ MSYS2 UCRT64.
- Visual Studio Code.

## 4. Hướng dẫn biên dịch

Mở MSYS2 UCRT64 và chuyển đến thư mục dự án:

`cd ~/hello-oss-doc`

Biên dịch chương trình bằng GCC:

`gcc main.c -o hello-oss.exe`

## 5. Hướng dẫn chạy chương trình

Sau khi biên dịch thành công, thực hiện lệnh:

`./hello-oss.exe`

Kết quả hiển thị:

`Hello OSS`

## 6. Đóng góp cho dự án

Người dùng có thể đóng góp bằng cách báo cáo lỗi, đề xuất cải tiến hoặc gửi Pull Request trên GitHub.

Vui lòng tham khảo file CONTRIBUTING.md để biết thêm chi tiết về quy trình đóng góp.
